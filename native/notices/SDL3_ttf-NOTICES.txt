Pysual native Windows text-engine notices
========================================

The official SDL3_ttf 3.2.2 Windows development package includes the
following text-engine components within SDL3_ttf.dll. These notices accompany
the DLL in Pysual native Windows distributions. The SDL_ttf notice itself is
provided separately as SDL3_ttf-3.2.2-LICENSE.txt.

This software is based in part on the work of the FreeType Team.
FreeType: https://freetype.org/

The exact upstream notice texts follow in separate files. FreeType's license
index also identifies the BDF and PCF driver notices, retained here in their
original README files. Upstream notice files have not been edited.
