Pysual web bundle runtime notices

The browser build embeds an unmodified Pyodide 0.29.0 npm runtime.
Pyodide is distributed under the Mozilla Public License 2.0.
Source: https://github.com/pyodide/pyodide/tree/0.29.0
License: Pyodide-LICENSE.txt
Distribution: https://registry.npmjs.org/pyodide/-/pyodide-0.29.0.tgz

The runtime's lock metadata identifies CPython 3.13.2.
CPython-LICENSE.txt preserves its complete upstream Doc/license.rst, including
the incorporated-software notices (such as Mersenne Twister, SipHash, expat,
and libmpdec). Optional/platform-specific terms are retained; this does not
mean every component listed there is present in this WebAssembly build.
Source: https://github.com/python/cpython/tree/v3.13.2
Pysual does not modify the interpreter or standard library distribution.

Additional runtime notices are provided for Emscripten 4.0.9 and its musl libc,
libffi, hiwire, MiniLZ4, bzip2, zlib, and CPython's HACL SHA2 implementation.
musl-INCORPORATED-NOTICES.txt preserves the separate math, complex, TRE regex,
crypt, and smoothsort notices referenced by musl-COPYRIGHT.txt.
LLVM-RUNTIME-LICENSES.txt preserves complete compiler-rt, libc++, libc++abi,
and libunwind notices, including LLVM exceptions and legacy terms. Optional
and alternate implementations are retained conservatively; their presence
does not assert that every component is linked into this runtime. See
manifest.json for exact upstream versions/commits, source locations, extraction
details and SHA256 hashes. Pyodide's pinned build files and Emscripten's port
definitions establish this inventory. MPL-covered Pyodide and hiwire source is
available from those version-pinned upstream source locations.
Hiwire source: https://github.com/pyodide/hiwire/tree/6a1e67280a15d929ebeceee54a6358c9c8d5f697

The builder validates this inventory before publishing and includes every
listed notice in both the HTML text block and embedded Python archive. When
updating the runtime, review its compiled components and update the matching
notices and hashes together. Pure Python source notices remain in the embedded
standard-library archive. Additional application packages need their own notices.

DejaVu Sans is bundled for matching window and browser typography.
Source: https://dejavu-fonts.github.io/
License and copyright notices: DejaVu-LICENSE.txt

The full license texts are included in the HTML's pysual-notices text block
and in the embedded Python archive under pysual/web/notices/ and pysual/assets/.
